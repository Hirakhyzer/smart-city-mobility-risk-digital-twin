# Data Policy

This repository is synthetic-first. The default workflow generates fictional city zones, roads, transit stops, emergency facilities, vehicles, traffic traces, incidents, and scenario outputs.

Do not commit real GPS traces, license-plate data, phone-location records, emergency dispatch records, camera feeds, transit smart-card records, or personally identifiable mobility data.

For real-world use, add a documented data-governance process covering consent, anonymization, aggregation, retention, security review, and city/stakeholder approval.
