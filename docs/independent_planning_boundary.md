# Independent Planning Boundary

This repository is an independent synthetic planning simulator. It is designed for research, education, and transparent scenario analysis.

It is not:

- traffic-signal control software
- emergency dispatch software
- road-closure guidance
- public warning infrastructure
- congestion-pricing certification
- policing or surveillance infrastructure
- transport-equity legal certification
- official city policy approval software

Real-world deployment requires city data governance, transport engineering, emergency-services review, accessibility review, environmental review, public consultation, security review, privacy review, and human oversight.

Synthetic scores are review prompts. They should be interpreted by qualified humans and never used as automatic decisions affecting public safety, mobility access, or public services.
